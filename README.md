# Retail Analytics ETL Project

## Описание
Проект демонстрирует построение ETL-пайплайна для розничных данных:
- Нормализация схемы «Звезда» (клиенты, товары, продажи)
- Очистка данных: дедупликация, детекция аномалий (отрицательная выручка, статистические выбросы)
- Инкрементальная загрузка в фактовую таблицу
- Построение витрины `customer_lifetime_mart` с RFM-сегментацией
- Оптимизация запросов через индексы

## Стек
- PostgreSQL
- SQL (оконные функции, CTE, индексы)
- Git / GitHub

## Структура проекта
- `/src` — SQL-скрипты (создание таблиц, ETL, аналитика)
- `/tests` — проверки качества данных

## Запуск
1. Выполнить `00_create_tables.sql`.
2. Выполнить `05_etl_cleaning.sql` для ETL-процесса.
3. Запустить `04_customer_lifetime_mart.sql` для построения витрины.
4. (Опционально) Выполнить `06_indexes.sql` для оптимизации.

## Результат
- Витрина с RFM-скорами позволяет сегментировать клиентов (Champions, Lost, etc.).
- ETL-пайплайн автоматически очищает сырые данные и загружает их в фактовую таблицу.
